## Project Overview

This project analyzes Netflix Movies and TV Shows data using PostgreSQL.

The objective is to solve real-world business problems and generate insights from Netflix content using SQL.

---

## Tools Used

* PostgreSQL
* SQL
* GitHub

---

## Dataset

Netflix Movies and TV Shows Dataset

https://www.kaggle.com/datasets/shivamb/netflix-shows

---

## Business Problems Solved

### Core Analysis

1. Count Movies vs TV Shows
2. Most Common Rating by Content Type
3. Top 5 Countries with Most Content
4. Longest Movie on Netflix
5. TV Shows with More Than 5 Seasons
6. Content Distribution by Genre
7. Top 5 Years with Highest Indian Content Releases
8. Documentary Movies Analysis
9. Top 10 Actors in Indian Movies
10. Content Classification using Keywords

### Advanced Analysis

11. Director with Highest Average Movie Duration
12. Country with Most Genre Diversity
13. Year-over-Year Netflix Content Growth %
14. Directors Who Created Both Movies and TV Shows
15. Most Dominant Rating in Each Country
